# IGAMM - IGA Multimodal

Projet de recherche sur l'IGA Multimodal (Interaction Gestuelle et Audio / Interface Graphique Avancée Multimodale).

## Structure du projet

- `src/` : Code source
- `data/` : Jeux de données (non versionnés)
- `docs/` : Documentation et notes de recherche
- `notebooks/` : Expérimentations et analyses
